## 通用底座能做什么

| 能力 | 可以这样使用 |
| --- | --- |
| 读取当前网页 | 提取页面文字、链接和可见控件，按问题整理信息 |
| 操作网页 | 点击、输入、搜索框填写、滚动、前进/后退、条件等待 |
| 表单与控件 | 原生下拉框、勾选、主文档拖放和画布相对位置拖动 |
| 文件与截图 | 上传你指定的文件，下载页面实际 HTTP(S) 链接，保存真实页面截图 |
| 管理任务标签 | 复用已有网站页面，新建、切换、关闭任务标签，同站页面归组 |
| 工作窗口授权 | 在一格弹窗授权一次，该窗口内普通网页无需逐页共享；随时撤销 |
| 会话保护 | 不同会话隔离；动作结果不明时先观察，不自动重发 |

例如：“整理我共享的产品页面”“帮我填写这份表单，提交前停下”“按这份资料修改我授权的网页设置”。

具体任务能否完成，取决于页面结构、账号权限和模型。**能点击按钮不代表业务已经成功**，应读取实际结果。发布、评论、支付、删除等操作，须在用户明确授权及适用网站规则允许的范围内进行。

手工配置看 [INSTALL.md](INSTALL.md)；第一次使用看 [一步一步安装说明](QUICKSTART.zh-CN.md)。使用现有 Chrome 登录状态不需要把账号密码或 Cookie 交给维护者。

## 兼容性、边界与隐私

- 本次包面向 Windows x64、Chrome、Codex 本地 MCP。其他 stdio MCP 客户端可用通用配置示例，但须单独验证兼容性。
- macOS、Linux、ARM64 暂无完整验收的发行包；完整 iframe、脚本/blob 下载和自动升级仍有缺口。
- 只接入明确共享的标签或工作窗口，其他窗口不自动授权。Chrome 完全退出后需重新授权。
- 扩展需要页面脚本、标签、调试与任务下载等权限，执行仍受共享检查约束。通用包不含录音、ASR 或平台研究适配。
- 页面内容可能通过工具结果发给所选模型。“本地桥接”不等于页面内容不离开电脑。
- 不上传本机配对文件，不交出浏览器存储；反馈前遮盖账号、客户资料和密钥。详见 [安全与隐私](SECURITY.md)。
