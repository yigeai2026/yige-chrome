**让 Codex 和支持 MCP 的 AI 客户端，操作你主动共享的 Chrome 页面。**

这是公开的安装、下载与反馈入口。开发源码仓库保持私有，软件按免费试用许可提供，**不是开源项目**。
试用允许使用，禁止修改和转售一格自有代码；第三方组件依原许可证。发行包中的 JavaScript 可读取，不能承诺技术防复制。

## 把这一段发给 Codex

> 请帮我安装一格：https://github.com/yigeai2026/yige-chrome 。先阅读 README.md、INSTALL.md 和 LICENSE.txt，说明许可和安装改动；我接受免费试用许可后，按安装指引完成下载、校验、本机配置和连接检查。保留已有模型及 MCP 配置，不操作未共享的浏览器页面。

Codex 需要能够在**你这台 Windows 电脑上执行本地命令**。仅能访问云端容器的会话不能安装到你的电脑。
账号登录或 API 登录不是安装器的区分条件；客户端必须支持本地 MCP，所用模型必须能够调用工具。所有客户端与登录组合尚未逐一验收。

## 安装会做什么

| 自动完成 | 用户需完成 |
| --- | --- |
| 下载约 44 MB 试用包并核对固定 SHA256 | 阅读并接受试用许可 |
| 解压、配置包内 Node 和配对信息 | 在 Chrome 中加载已解压扩展 |
| 为 Codex 添加 MCP 配置和 Agent skill | 重连/重启 Codex，让新 MCP 和 skill 生效 |
| 生成 Grok 等客户端的配置示例 | 在一格弹窗主动共享目标标签 |

安装不需要管理员权限、Git、npm 或预先安装 Node。需要已安装 Google Chrome，并能下载 GitHub Release。
不关闭浏览器，不强杀其他会话，不覆盖已有一格配置。首次安装未完成的步骤会明确列出，不把“文件下载成功”当作“浏览器连接成功”。

## 当前能力与边界

- 共享页面读取、查找控件、点击、填写、导航、条件等待、截图和有限诊断。
- Codex/Grok 共用浏览器核心；不同会话隔离，空闲共享标签自动认领。
- 抖音/小红书有专用日期、评论和媒体证据规则，按实际覆盖范围返回结果。
- 首批是 **Windows 10/11 x64，核心 0.5.7 / trial.1**。macOS、Linux、ARM64 暂不提供安装包。
- 尚无 Chrome 商店版本、一键自动升级、完整 iframe/拖拽覆盖或长期无人值守保证。
- 不绕过验证码。页面内容可能随工具结果发给所用模型服务，本地桥接不意味着页面内容不离开电脑。
